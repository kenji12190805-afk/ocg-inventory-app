"why":{"python":"case の行の最後に : が足りない。","javascript":"case の最後に break がないと、次の case も続けて実行される(フォールスルー)。エラーにならないので気づきにくい。","c":"case の最後に break がないと、次の case も続けて実行される(フォールスルー)。コンパイラが警告を出してくれることもある。","kotlin":"when を値として使うのに、else がない。どの値でもないときの結果が決まらない。"}}

=== javascript
const day = 3;
switch (day) {
  case 1:
    console.log("月");
    break;
  case 2:
    console.log("火");
    break;
  case 3:
    console.log("水");
    break;
  default:
    console.log("その他");
}

=== c
#include <stdio.h>

int main(void) {
    int day = 3;
    switch (day) {
        case 1:
            printf("Mon\n");
            break;
        case 2:
            printf("Tue\n");
            break;
        case 3:
            printf("Wed\n");
            break;
        default:
            printf("other\n");
            break;
    }
    return 0;
}
