"notes":{"python":"型を書かなくていい。あとから別の型を入れることもできる。","javascript":"変えない値は const、変える値は let を使う(var は古い書き方)。","c":"型を必ず書く。小数は double、1文字は char('A')。","kotlin":"変えない値は val、変える値は var。型は自動で推測してくれる。"},
"why":{"python":"変数名のタイプミス(name → nmae)。存在しない名前は使えない。","javascript":"const で作った変数は、あとから入れ直せない。","c":"変数名のタイプミス(age → agee)。C は宣言していない名前を使えない。","kotlin":"val で作った変数は、あとから入れ直せない。"}}

name = "ケンジ"
age = 30

print(name, age, price)

}
